REST API

Trzy endpointy do zarządzania dziennikiem treningów. Każde żądanie wymaga nagłówka Authorization: Bearer <TOKEN>.

Autoryzacja

Każde żądanie musi zawierać nagłówek Authorization z tokenem Bearer.

Token generujesz w pasku powyżej — widoczny tylko raz. Zapisz go zanim zamkniesz stronę. 
Authorization: Bearer <TOKEN>
Content-Type: application/json
POST

Create — nowy trening

Dodaje nowy wpis treningowy do dziennika. Jeźdźca wyszukuje po imieniu (częściowe dopasowanie, case-insensitive) — wystarczy wpisać kilka liter. Jeśli imię pasuje do więcej niż jednej osoby, endpoint zwraca listę kandydatów zamiast tworzyć wpis.

POSThttps://asxvphinpnhjfrqibfka.supabase.co/functions/v1/nowy-trening
Koń jest opcjonalny — wpis pojawi się w dzienniku bez przypisanego konia. Pole data domyślnie przyjmuje dzisiejszą datę z serwera.
Body parameters
ParametrTypOpis
jezdziecrequiredstringImię jeźdźca lub fragment (np. "Kas" znajdzie Kasię). Szuka case-insensitive po kolumnie imie.
konoptionalstringImię konia (też częściowe dopasowanie). Gdy niejednoznaczne, endpoint zwraca błąd z kandydatami.
dataoptionalstringData treningu w formacie YYYY-MM-DD. Domyślnie dzisiejsza data.
typ_jazdyoptionalenumplac (domyślnie) · teren · skoki · ujeżdżenie · lonża · inne
ocenaoptionalinteger 1–5Ocena treningu. Musi być liczbą całkowitą od 1 do 5.
cwiczeniaoptionalstring[]Tablica nazw ćwiczeń wykonanych na treningu, np. ["Cavaletti w kłusie", "Ósemka"].
uwagioptionalstringOgólne uwagi instruktora z treningu.
dobrzeoptionalstringCo poszło dobrze na tym treningu.
do_poprawyoptionalstringCo wymaga poprawy — pole do śledzenia postępów.

POST

Ask — zapytaj agenta

Zadaje pytanie agentowi AI Cwałek w języku naturalnym. Agent automatycznie zaciąga kontekst z bazy — treningi z danego dnia, listę jeźdźców i koni. Gdy potrzebuje danych historycznych, wywołuje narzędzia wewnętrzne (pobierz_treningi, pobierz_jezdzca) i odpowiada po zebraniu wszystkich informacji. Może zająć do kilku sekund.

POSThttps://asxvphinpnhjfrqibfka.supabase.co/functions/v1/zapytaj
Agent używa modelu Grok-4.3 (xAI) z pętlą agentic do max 5 iteracji. Timeout na Vercelu ustawiony na 60 s. Odpowiedź zawsze jest w polu odpowiedz.
Body parameters
ParametrTypOpis
pytanierequiredstringPytanie w języku naturalnym, np. „Jak postępuje Kasia?", „Ile treningów było w tym tygodniu?", „Co ćwiczyliśmy najczęściej?"
dataoptionalstringDzień kontekstu w formacie YYYY-MM-DD. Agent widzi treningi z tego dnia jako „dzisiejsze". Domyślnie: dzisiaj.
Przykładowe żądanie
curl -X POST https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/zapytaj \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"pytanie":"Jak postępuje Kasia w ostatnim miesiącu?","data":"2026-06-15"}'
const { odpowiedz } = await fetch("https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/zapytaj", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    pytanie: "Jak postępuje Kasia w ostatnim miesiącu?",
    data: "2026-06-15",
  }),
}).then(r => r.json());

console.log(odpowiedz); // tekst odpowiedzi agenta

Read — treningi dnia

Zwraca wszystkie wpisy treningowe z podanego dnia, posortowane chronologicznie. UUID jeźdźców i koni są automatycznie zdekodowane na czytelne imiona. Gdy brak treningów dla danej daty, zwraca pustą tablicę i liczba: 0.

GEThttps://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia?data=2026-06-15
Query parameters
ParametrTypOpis
dataoptionalstringData w formacie YYYY-MM-DD. Domyślnie dzisiejsza data. Nieprawidłowy format zwraca błąd 400.
Przykładowe żądanie
curl "https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia?data=2026-06-15" \
  -H "Authorization: Bearer <TOKEN>"
const { data, liczba, treningi } = await fetch(
  "https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia?data=2026-06-15",
  { headers: { "Authorization": `Bearer ${TOKEN}` } }
).then(r => r.json());

console.log(`${liczba} treningów dnia ${data}`);
res = requests.get(
    "https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia",
    params={"data": "2026-06-15"},
    headers={"Authorization": f"Bearer {TOKEN}"},
)
payload = res.json()
for t in payload["treningi"]:
    print(t["jezdziec"], t["typ_jazdy"], t["ocena"])

MCP Server

Model Context Protocol — standardowy interfejs, dzięki któremu agenci AI (Claude, Cursor, n8n…) korzystają z dziennika bezpośrednio, bez pisania kodu HTTP.

MCP server to cienka warstwa proxy między klientem AI a istniejącymi edge functions. Używa tego samego tokenu co REST API.
Jak to działa
1

Klient AI wywołuje tool

np. Claude Desktop prosi o add_training z parametrami.

2

MCP server (Vercel) tłumaczy żądanie

Waliduje token, mapuje parametry i wywołuje odpowiedni Supabase edge function.

3

Odpowiedź wraca do agenta

JSON z bazy trafia z powrotem do klienta AI jako wynik tool call.

URL serwera MCP
https://mcp-server-phi-seven.vercel.app/mcp

Wdrożenie na Vercel

Serwer jest już wdrożony. Pliki źródłowe w deploy/mcp-server/ — by ponownie wdrożyć po zmianach:

cd deploy/mcp-server
npx vercel deploy --prod
Vercel automatycznie wykrywa TypeScript. Routing /mcp → api/mcp.ts skonfigurowany w vercel.json.

Konfiguracja klientów

MCP server działa z każdym klientem obsługującym Streamable HTTP.

Claude Desktop

Edytuj claude_desktop_config.json (macOS: ~/Library/Application Support/Claude/, Windows: %APPDATA%\Claude\).

ask_agent

Zadaje pytanie agentowi AI Cwałek i zwraca odpowiedź w naturalnym języku. Proxy dla REST POST /zapytaj. Agent (Grok-4.3) automatycznie sięga po dane z bazy — możesz pytać o dowolnego jeźdźca lub dowolny dzień bez podawania ID.

toolask_agent
Model: Grok-4.3 (xAI). Pętla agentyczna do 5 iteracji — może wywołać wewnętrzne narzędzia (pobierz_treningi, pobierz_jezdzca) zanim odpowie. Limit: maxDuration: 60s.
Parametry
ParametrTypOpis
pytanierequiredstringPytanie w języku naturalnym. Może dotyczyć postępów jeźdźca, podsumowania dnia, porównania zajęć itp.
dataoptionalstringDzień kontekstu YYYY-MM-DD. Agent używa tej daty przy pobieraniu treningów. Domyślnie dzisiaj.
Przykład wywołania
result = await session.call_tool("ask_agent", {

REST API

Trzy endpointy do zarządzania dziennikiem treningów. Każde żądanie wymaga nagłówka Authorization: Bearer <TOKEN>.

Autoryzacja

Każde żądanie musi zawierać nagłówek Authorization z tokenem Bearer.

Token generujesz w pasku powyżej — widoczny tylko raz. Zapisz go zanim zamkniesz stronę. 
Authorization: Bearer <TOKEN>
Content-Type: application/json
POST

Create

Dodaje nowy wpis treningowy. Jeźdźca wyszukuje po imieniu (częściowe dopasowanie). Zwraca błąd gdy imię niejednoznaczne.

POSThttps://asxvphinpnhjfrqibfka.supabase.co/functions/v1/nowy-trening
Body parameters
ParametrTypOpis
jezdziecrequiredstringImię jeźdźca (lub fragment).
konoptionalstringImię konia.
dataoptionalstringData YYYY-MM-DD. Domyślnie dzisiaj.
typ_jazdyoptionalstringplac · teren · skoki · ujeżdżenie · lonża · inne
ocenaoptionalnumberOcena 1–5.
cwiczeniaoptionalstring[]Lista ćwiczeń.
uwagioptionalstringOgólne uwagi z treningu.
dobrzeoptionalstringCo poszło dobrze.
do_poprawyoptionalstringCo wymaga poprawy.
Przykładowe żądanie
curl -X POST https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/nowy-trening \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"jezdziec":"Kasia","kon":"Bryza","ocena":4,"cwiczenia":["Koła 20m"]}'
const res = await fetch("https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/nowy-trening", {
  method: "POST",
  headers: { "Authorization": `Bearer ${TOKEN}`, "Content-Type": "application/json" },
  body: JSON.stringify({ jezdziec: "Kasia", kon: "Bryza", ocena: 4 }),
});
res = requests.post(
    "https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/nowy-trening",
    headers={"Authorization": f"Bearer {TOKEN}"},
    json={"jezdziec": "Kasia", "kon": "Bryza", "ocena": 4},
)
Odpowiedź
{ "id": "3be52fa6-...", "data": "2026-06-15", "jezdziec": "Kasia", "ocena": 4 }
{ "error": "Nie znaleziono jeźdźca: \"Kasia\"." }

POST

Ask

Zadaje pytanie agentowi AI Cwałek. Agent automatycznie pobiera kontekst z bazy.

POSThttps://asxvphinpnhjfrqibfka.supabase.co/functions/v1/zapytaj
Body parameters
ParametrTypOpis
pytanierequiredstringPytanie w języku naturalnym.
dataoptionalstringDzień kontekstu YYYY-MM-DD. Domyślnie dzisiaj.
Przykładowe żądanie
curl -X POST https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/zapytaj \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"pytanie":"Jak postępuje Kasia?","data":"2026-06-15"}'
const { odpowiedz } = await fetch("https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/zapytaj", {
  method: "POST",
  headers: { "Authorization": `Bearer ${TOKEN}`, "Content-Type": "application/json" },
  body: JSON.stringify({ pytanie: "Jak postępuje Kasia?" }),
}).then(r => r.json());
Odpowiedź
{ "odpowiedz": "Kasia ma 6 treningów w ostatnim miesiącu. Widać postęp w galopie — oceny wzrosły z 3 do 5. 💪" }
{ "error": "Pole 'pytanie' jest wymagane." }

Read

Zwraca wszystkie wpisy treningowe z podanego dnia. Imiona zdekodowane — bez UUID.

GEThttps://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia?data=2026-06-15
Query parameters
ParametrTypOpis
dataoptionalstringData YYYY-MM-DD. Domyślnie dzisiaj.
Przykładowe żądanie
curl "https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia?data=2026-06-15" \
  -H "Authorization: Bearer <TOKEN>"
const { treningi } = await fetch(
  "https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia?data=2026-06-15",
  { headers: { "Authorization": `Bearer ${TOKEN}` } }
).then(r => r.json());
Odpowiedź
{
  "data": "2026-06-15", "liczba": 1,
  "treningi": [{
    "jezdziec": "Kasia", "kon": "Bryza", "typ_jazdy": "plac", "ocena": 4
  }]
}
{ "error": "Nieprawidłowy format daty. Użyj YYYY-MM-DD." }

MCP Server

Model Context Protocol — standardowy interfejs, dzięki któremu agenci AI (Claude, Cursor, n8n…) korzystają z dziennika bezpośrednio, bez pisania kodu HTTP.

MCP server to cienka warstwa proxy między klientem AI a istniejącymi edge functions. Używa tego samego tokenu co REST API.
Jak to działa
1

Klient AI wywołuje tool

np. Claude Desktop prosi o add_training z parametrami.

2

MCP server (Vercel) tłumaczy żądanie

Waliduje token, mapuje parametry i wywołuje odpowiedni Supabase edge function.

3

Odpowiedź wraca do agenta

JSON z bazy trafia z powrotem do klienta AI jako wynik tool call.

URL serwera MCP
https://mcp-server-phi-seven.vercel.app/mcp

Wdrożenie na Vercel

Serwer jest już wdrożony. Pliki źródłowe w deploy/mcp-server/ — by ponownie wdrożyć po zmianach:

cd deploy/mcp-server
npx vercel deploy --prod
Vercel automatycznie wykrywa TypeScript. Routing /mcp → api/mcp.ts skonfigurowany w vercel.json.

Konfiguracja klientów

MCP server działa z każdym klientem obsługującym Streamable HTTP.

Claude Desktop

Edytuj claude_desktop_config.json (macOS: ~/Library/Application Support/Claude/, Windows: %APPDATA%\Claude\).

{
  "mcpServers": {
    "dziennik": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp-server-phi-seven.vercel.app/mcp",
        "--header",
        "Authorization: Bearer <TOKEN>"
      ]
    }
  }
}

Python SDK
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

TOKEN = "dziennik_..."
URL   = "https://mcp-server-phi-seven.vercel.app/mcp"

async with streamablehttp_client(URL, headers={"Authorization": f"Bearer {TOKEN}"}) as (r, w, _):
    async with ClientSession(r, w) as session:
        await session.initialize()
        tools = await session.list_tools()
        # ['add_training', 'get_trainings', 'ask_agent']

Zadaje pytanie agentowi AI Cwałek. Odpowiada REST POST /zapytaj.

toolask_agent
Parametry
ParametrTypOpis
pytanierequiredstringPytanie w języku naturalnym.
dataoptionalstringDzień kontekstu YYYY-MM-DD. Domyślnie dzisiaj.
Ten tool wywołuje model AI i może zająć kilka sekund. Vercel ustawiony na maxDuration: 60s.

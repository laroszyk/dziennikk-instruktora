API Reference

REST API do zarządzania dziennikiem treningów. Trzy endpointy pozwalają dodawać wpisy, odpytywać agenta AI i pobierać treningi z danego dnia.

Autoryzacja

Każde żądanie musi zawierać nagłówek Authorization z tokenem Bearer.

Token API znajdziesz w ustawieniach projektu Supabase → Edge Function Secrets → API_SECRET_KEY. Nie udostępniaj go publicznie. 
Authorization: Bearer <API_SECRET_KEY>
Content-Type: application/json
POST

Create

Dodaje nowy wpis treningowy do bazy. Jeźdźca wyszukuje po imieniu (częściowe dopasowanie). Zwraca błąd, gdy imię jest niejednoznaczne — wtedy podaj dokładniejsze.

POST https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/nowy-trening
Body parameters
ParametrTypOpis
jezdziecrequired string Imię jeźdźca (lub fragment). Dopasowanie case-insensitive.
konoptional string Imię konia. Jeśli nie podano — pole zostaje puste.
dataoptional string Data treningu w formacie YYYY-MM-DD. Domyślnie dzisiaj.
typ_jazdyoptional string Jeden z: plac, teren, skoki, ujeżdżenie, lonża, inne. Domyślnie plac.
ocenaoptional number Ocena treningu od 1 do 5.
cwiczeniaoptional string[] Lista ćwiczeń wykonanych podczas treningu.
uwagioptional string Ogólne uwagi z treningu.
dobrzeoptional string Co poszło dobrze.
do_poprawyoptional string Co wymaga poprawy.
Przykładowe żądanie
curl -X POST https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/nowy-trening \
  -H "Authorization: Bearer <API_SECRET_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "jezdziec": "Kasia",
    "kon": "Bryza",
    "ocena": 4,
    "typ_jazdy": "plac",
    "cwiczenia": ["Koła 20 m", "Kłus bez strzemion"],
    "dobrze": "Dobry rytm w kłusie",
    "do_poprawy": "Praca łydką w zakrętach"
  }'

POST

Ask

Zadaje pytanie agentowi AI Cwałek. Endpoint automatycznie pobiera kontekst dnia z bazy — nie musisz podawać danych treningów w żądaniu. Agent ma dostęp do pełnej historii i może wyszukiwać dane z innych dni.

POST https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/zapytaj
Body parameters
ParametrTypOpis
pytanierequired string Pytanie do agenta w dowolnym języku naturalnym.
dataoptional string Dzień kontekstu w formacie YYYY-MM-DD. Treningi z tego dnia trafiają do promptu systemowego. Domyślnie dzisiaj.
Przykładowe żądanie
curl -X POST https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/zapytaj \
  -H "Authorization: Bearer <API_SECRET_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "pytanie": "Jak postępuje Kasia w ostatnim miesiącu?",
    "data": "2026-06-15"
  }'
const res = await fetch("https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/zapytaj", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${API_SECRET_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    pytanie: "Jak postępuje Kasia w ostatnim miesiącu?",
    data: "2026-06-15",
  }),
});
const { odpowiedz } = await res.json();
console.log(odpowiedz);
res = requests.post(
    "https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/zapytaj",
    headers={"Authorization": f"Bearer {API_SECRET_KEY}"},
    json={
        "pytanie": "Jak postępuje Kasia w ostatnim miesiącu?",
        "data": "2026-06-15",
    },
)
print(res.json()["odpowiedz"])
Odpowiedź
{
  "odpowiedz": "Kasia w ostatnim miesiącu miała 6 treningów — oceny wahają się od 3 do 5. Widać wyraźny postęp w galopie, anglezowanie zdecydowanie pewniejsze. Warto teraz skupić się na pracy bez strzemion dla lepszej równowagi. 💪"
}
{ "error": "Pole 'pytanie' jest wymagane." }
GET

Read

Zwraca wszystkie wpisy treningowe z podanego dnia. Imiona jeźdźców i koni są już zdekodowane — bez surowych UUID. Jeśli nie podasz daty, zwraca treningi z dzisiaj.

GET https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia?data=2026-06-15
Query parameters
ParametrTypOpis
dataoptional string Data w formacie YYYY-MM-DD. Domyślnie dzisiaj.
Przykładowe żądanie
curl "https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia?data=2026-06-15" \
  -H "Authorization: Bearer <API_SECRET_KEY>"
const res = await fetch(
  "https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia?data=2026-06-15",
  { headers: { "Authorization": `Bearer ${API_SECRET_KEY}` } }
);
const { treningi } = await res.json();
console.log(treningi);
res = requests.get(
    "https://asxvphinpnhjfrqibfka.supabase.co/functions/v1/trening-dnia",
    headers={"Authorization": f"Bearer {API_SECRET_KEY}"},
    params={"data": "2026-06-15"},
)
print(res.json())

Personal Access Tokens

Tokeny pozwalają na dostęp do API bez używania master klucza. Każdy token możesz odwołać osobno. Token jest pokazywany tylko raz — po wygenerowaniu zapisz go.

⚠ Zapisz ten token — nie będzie pokazany ponownie.

Kody błędów

KodZnaczenie
401Brak lub nieprawidłowy token Bearer.
400Błąd walidacji — brakujące pole, niejednoznaczne imię lub nieprawidłowy format.
404Nie znaleziono jeźdźca lub konia o podanej nazwie.
405Niedozwolona metoda HTTP.
500Błąd serwera — problem z bazą danych lub API modelu AI.
